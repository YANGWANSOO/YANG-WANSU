# 사이드뷰 대전 격투 게임 제작 프롬프트

> 작성일: 2026-11-18
> 목적: AI로 웹 브라우저에서 실행되는 2D 사이드뷰 격투 게임을 만들 때 쓰는 프롬프트 모음

## 만들려는 게임 형식

- 실행하면 로딩 후 캐릭터 선택 화면으로 이동
- 캐릭터를 선택하면 자신의 캐릭터와 적 캐릭터(NPC)가 대전 격투 게임 방식으로 전투 시작
- 이동: WASD, 방어: S, 일반공격: J(연계기 가능), K: 짧은 대시, L: 필살기, 이동키와 공격키를 연계해 다양한 공격·회피 발동
- 적 캐릭터를 쓰러트리면 증강(능력치 상승이나 특수능력 부여)을 선택하고 다음 스테이지로 이동
- 스테이지가 올라갈수록 난이도 상승

## 진행 방식

프롬프트 하나로 한 번에 만들면 버그가 많이 생긴다. **전체 설계를 알려 주는 기본 프롬프트로 뼈대를 만들고, 단계별 프롬프트로 하나씩 덧붙이는 방식**이 가장 안정적이다.

---

## 0. 먼저 정해 둘 것: 조작 충돌

요청한 조작에서 **S가 '아래'와 '방어'를 함께 맡고 있다.** AI가 헷갈리지 않게 미리 정해 준다. 아래 프롬프트는 이렇게 정리했다. 다르게 하고 싶으면 이 부분만 고친다.

- **S 단독:** 서서 방어
- **S + 공격키:** 하단 공격 (앉아서 공격)
- **W:** 점프

---

## 1. 기본 프롬프트 (가장 먼저 한 번)

```
너는 숙련된 HTML5 게임 개발자야. 웹 브라우저에서 바로 실행되는 2D 사이드뷰 대전 격투 게임을 만들어 줘.

[기술 조건]
- HTML 파일 1개 안에 HTML, CSS, JavaScript를 모두 넣어 줘. 외부 라이브러리나 이미지 파일은 쓰지 마.
- Canvas 2D로 그리고, 캐릭터는 도형(사각형, 원, 선)으로 표현해. 나중에 스프라이트 이미지로 바꾸기 쉽게 그리기 코드를 캐릭터별 함수로 분리해 줘.
- 60fps 고정 업데이트(requestAnimationFrame + 델타타임)로 만들어 줘.
- 코드는 Game, Scene, Fighter, AI, Stage, Augment 같은 역할별 클래스로 나눠 줘.

[화면 흐름]
1. 로딩 화면: 진행 바가 1~2초 동안 차오른 뒤 자동으로 넘어감
2. 캐릭터 선택 화면: 캐릭터 3명 중 하나를 A/D로 고르고 J로 결정. 각 캐릭터의 체력, 속도, 공격력을 막대로 보여 줘.
3. 전투 화면: 플레이어(왼쪽) 대 NPC(오른쪽). 위쪽에 양쪽 체력바, 필살기 게이지, 스테이지 번호, 시작할 때 "ROUND START" 표시
4. 승리하면 증강 선택 화면으로, 패배하면 게임 오버 화면(재시작 / 캐릭터 선택으로)

[조작]
- A/D: 좌우 이동, W: 점프
- S 단독: 방어 (막으면 피해 80% 감소, 살짝 밀려남)
- J: 일반 공격. 타이밍 맞춰 연타하면 3단 콤보(약-약-강)로 이어짐. 3타째는 상대를 날려 버림
- K: 짧은 대시. 이동 방향(A/D)으로 나가고, 대시 중 짧은 무적 시간이 있음
- L: 필살기. 필살기 게이지가 꽉 찼을 때만 사용 가능
- 방향키 + 공격키 조합 기술:
  - S + J: 하단 공격 (방어하지 않은 상대를 넘어뜨림)
  - W + J 또는 점프 중 J: 공중 공격
  - 앞 + J: 돌진 찌르기
  - 뒤 + K: 백스텝 회피 (무적 시간이 더 긴 대신 짧게 이동)
  - 대시 중 J: 대시 공격

[전투 시스템]
- 공격마다 판정 박스(히트박스)와 피격 박스(허트박스)를 따로 두고, 맞으면 경직, 넉백, 짧은 히트스톱(멈춤 효과)을 줘.
- 공격은 '준비 → 공격 판정 → 후딜레이' 3단계 프레임으로 나눠 줘.
- 때리거나 맞으면 필살기 게이지가 참.
- 두 캐릭터는 항상 서로를 바라보게 해 줘.
- 화면 양 끝에 벽을 둬.

[NPC AI]
- 거리에 따라 다가가기, 공격, 방어, 대시, 거리 벌리기 중에서 고르는 상태 기반 AI
- 반응 속도, 방어 확률, 콤보 사용 확률, 공격 빈도를 숫자로 조절할 수 있게 만들어 줘 (난이도에 사용)

[증강]
- 승리하면 카드 3장 중 1장을 고름 (A/D로 이동, J로 결정)
- 능력치형: 최대 체력 +20%, 공격력 +15%, 이동 속도 +10%, 필살기 게이지 충전 +25%
- 특수 능력형: 흡혈(입힌 피해의 10% 회복), 대시 후 다음 공격 2배, 방어 성공 시 반격, 체력 30% 이하일 때 공격력 증가, 2단 점프
- 고른 증강은 다음 스테이지에도 계속 유지되고, 전투 화면 구석에 아이콘으로 표시

[스테이지와 난이도]
- 스테이지가 올라갈 때마다 NPC 체력, 공격력, 반응 속도, 방어 확률이 올라감
- 3스테이지마다 더 강한 보스 NPC가 나옴
- 스테이지마다 배경 색을 바꿔 줘
- 다음 스테이지로 가면 플레이어 체력을 일부만 회복

먼저 전체 코드 구조를 짧게 설명한 다음, 실행 가능한 완성 코드를 줘.
```

## 2. 단계별 추가 프롬프트 (결과를 보면서 하나씩)

### ① 조작감 다듬기

```
조작감을 다듬어 줘. 입력 버퍼(공격 버튼을 조금 일찍 눌러도 다음 동작으로 이어지게 0.15초 정도 기억하기)를 넣고, 콤보 입력 시간을 넉넉하게 해 줘. 점프는 누르는 시간에 따라 높이가 달라지게 해 줘.
```

### ② 캐릭터 개성

```
캐릭터 3명의 개성을 확실하게 나눠 줘.
- 밸런스형: 보통 속도, 필살기는 앞으로 나가는 연속 베기
- 스피드형: 빠르고 체력 낮음, 콤보가 4단까지, 필살기는 순간이동 연타
- 파워형: 느리고 체력 높음, 공격 한 번이 강함, 필살기는 화면 절반을 덮는 충격파
캐릭터마다 색상과 실루엣도 다르게 해 줘.
```

### ③ 타격감 연출

```
타격감을 높여 줘. 맞을 때 화면 흔들림, 작은 파편 이펙트, 데미지 숫자 표시를 넣고, 필살기를 쓰면 화면이 잠깐 어두워지면서 컷인 연출이 나오게 해 줘. 효과음은 외부 파일 없이 Web Audio API로 만들어 줘.
```

### ④ 난이도 밸런스

```
난이도 곡선을 표로 정리해 줘. 1~10스테이지의 NPC 체력, 공격력, 반응 시간, 방어 확률, 콤보 확률을 표로 보여 주고, 그 값대로 코드에 반영해 줘. 1스테이지는 처음 해 보는 사람도 이길 수 있게 쉽게 해 줘.
```

### ⑤ 편의 기능

```
P로 일시정지하는 기능과, 조작법 안내 화면(캐릭터 선택 화면에서 H)을 넣어 줘. 최고 도달 스테이지는 localStorage에 저장해 줘.
```

## 3. 버그가 생겼을 때 쓰는 프롬프트

```
[문제] 3타 콤보 후에 캐릭터가 움직이지 않아.
[재현 방법] J를 빠르게 3번 누르면 매번 생김.
[기대 동작] 3타가 끝나면 다시 이동할 수 있어야 해.
원인을 먼저 설명하고, 고친 부분만 보여 준 다음 전체 코드도 다시 줘.
```

**문제 / 재현 방법 / 기대 동작** 세 가지를 적으면 AI가 훨씬 정확하게 고친다.

---

## 활용 팁

- **기본 프롬프트를 넣은 뒤에는 꼭 직접 실행해 보고** 다음 단계로 넘어간다. 여러 단계를 한꺼번에 요청하면 앞에서 잘 되던 기능이 망가지기 쉽다.
- **코드가 길어지면 AI가 "앞부분 생략"으로 줄여서 줄 때가 있다.** 그럴 땐 "생략 없이 전체 코드를 줘"라고 덧붙인다.
- **캐릭터 이름과 디자인은 직접 만든 것으로** 한다. 기존 격투 게임의 캐릭터나 기술 이름을 넣으면 저작권 문제가 생길 수 있고, AI가 거절하기도 한다.
- 나중에 그림을 넣고 싶으면, 이미지 생성 AI로 캐릭터 스프라이트 시트를 만든 뒤 "도형 그리기 함수를 이 스프라이트 시트로 바꿔 줘"라고 요청한다.
